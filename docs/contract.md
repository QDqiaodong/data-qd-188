# 棋谱回放模型 v1

自定义JSON：size=3..19；setup.black/white为0起[row,col]坐标，互不重叠且每个初始连通棋块必须有气；next_player=B/W，komi为绝对值≤100的有限小数字符串。初始设置不代表可从空盘达到的合法历史。moves最多2000条，有唯一ASCII id、player和point（坐标或null停一手）。不解析SGF、不连接对弈服务。

整份输入先检查结构、类型和身份；错误退出2且不发布。棋步依输入顺序，必须轮流。落子先检查棋盘范围和占用，随后提取无气对方棋块，再检查己方气。禁自杀；简单劫禁止落子后的盘面等于前一手之前盘面（含完整落子后的棋子位置，不含提子计数）。只采用simple ko，不实现全局同形、长生循环或赛事专有规则。停一手更新历史且不受劫限制。两次连续停手结束；之后再有棋步视为非法。

第一条非法步返回first_illegal，保留此前合法前缀，非法步及余下id列入unprocessed_move_ids；该步提子/落子不污染最终盘面。棋谱业务非法是正常报告，CLI退出0；summary.valid_record=false。trace记录每个合法步盘面和实际提子，按坐标排序提供证据。

对最终合法盘面求4邻接空域。边界棋子恰只有一种颜色的空域归该色，混色/无边界为空域中立。面积=盘上棋子+己方空域，白额外加komi；精确整数/分数字符串输出分差。没有自动死活、死子移除、双活专门判定或领地计分规则；未双停时明确provisional，双停后仍只按本模型计分。输出不等价于真实赛事裁定。棋子数+空域数严格守恒为size²。

成功原子新建JSON，拒绝已有目标文件或链接。没有持久棋谱修订库、搜索AI或联网对弈。
